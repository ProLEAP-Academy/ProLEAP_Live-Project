# Changelog

All significant revisions to the live-project framework are recorded here.

## 2.0.0 - 2026-08-18

### Changed
- Rebuilt the repository as an editable, GitHub-native Markdown project pack.
- Replaced the old two-page SCQ material with a structured discovery framework and reusable template.
- Replaced the old Solution Intent outline with a complete design-review document structure.
- Modernized Dynamic ETL while preserving all original BR1-BR29 requirements through explicit traceability.
- Modernized GitHub Aggregator into an asynchronous contributor-intelligence service with pagination, rate-limit handling, deduplication, privacy rules and secure GitHub App authentication.
- Replaced insecure/obsolete FTP-first design with secure-ingestion requirements while retaining a documented legacy compatibility path.

### Added
- Full business requirements for 360-Degree Monitoring.
- Full custom-project proposal and approval framework.
- Architecture, acceptance-criteria and test-plan documents for the three defined technical projects.
- Program governance, Definition of Done, assessment rubric, repository standards, security/data handling and AI-use policy.
- ADR, runbook, test-plan, risk-register, status-report and postmortem templates.
- GitHub pull-request and issue templates.
- Legacy archive and migration map.
