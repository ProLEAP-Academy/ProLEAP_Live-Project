# Custom Project Evaluation Criteria

A proposal is evaluated on a 0-2 scale in each category.

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Problem clarity | vague/tutorial | plausible but weak evidence | real, measurable problem |
| Engineering depth | single tool | several components | end-to-end system with operations |
| Scope realism | too small/large | needs adjustment | achievable and meaningful |
| Acceptance criteria | subjective | partially testable | measurable and evidence-driven |
| Security/data | ignored | basic notes | explicit safe design |
| Operability | no operations | basic logs | monitoring, recovery and runbook |
| Repeatability | manual demo | partially scripted | automated/reproducible |
| Learning alignment | weak | moderate | strong portfolio value |

Suggested approval threshold: **12/16**, with no zero in Security/Data or Acceptance Criteria.
