# Final Demo Checklist

## Before the demo

- [ ] Core environment is reproducible.
- [ ] Demo uses sanitized data.
- [ ] No credentials are visible on screen or in commands.
- [ ] Required dashboards/log views are prepared.
- [ ] Failure-injection step is safe and reversible.
- [ ] Acceptance evidence is accessible.

## Demo flow

- [ ] Explain problem and business outcome in <=3 minutes.
- [ ] Show architecture.
- [ ] Show repository and CI/CD path.
- [ ] Execute normal end-to-end flow.
- [ ] Show persisted/output result.
- [ ] Inject one controlled failure.
- [ ] Show alert/telemetry.
- [ ] Diagnose failure.
- [ ] Recover or rollback.
- [ ] Show final healthy state.
- [ ] State known limitations and future improvements.

## Final proof

- [ ] All Must requirements are mapped to evidence.
- [ ] Runbook works.
- [ ] Team can explain major design decisions without reading generated text.
