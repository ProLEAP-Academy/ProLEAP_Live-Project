# AI Use Policy for Live Projects

AI tools may be used as engineering assistants, but the learner remains accountable for every artifact and line of code submitted.

## Allowed

- brainstorming questions for SCQ;
- explaining unfamiliar errors;
- generating test-case ideas;
- proposing implementation options;
- reviewing code/doc structure;
- drafting boilerplate that the learner validates;
- generating sample data that contains no real sensitive data.

## Required controls

- Validate generated code before use.
- Run tests; do not treat AI output as evidence.
- Do not paste secrets or confidential/customer data into an AI service without explicit authorization.
- Record material AI-assisted decisions when they affect architecture/security.
- Be able to explain and troubleshoot submitted code without the AI tool.

## Not acceptable

- submitting generated code that the team cannot explain;
- fabricating logs, screenshots or test results;
- using AI to bypass project assessment;
- pasting production secrets/data into prompts;
- hiding material known failures in generated documentation.
