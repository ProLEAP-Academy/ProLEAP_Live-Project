# Code of Conduct

This repository is a professional learning environment.

Participants are expected to:

- give technical feedback on work, not people;
- document disagreements and resolve them through evidence, requirements and trade-offs;
- avoid harassment, discrimination and personal attacks;
- protect private/confidential information shared during project work;
- credit external work and avoid plagiarism;
- report serious conduct or security concerns privately to course/repository maintainers.

Project reviews may be strict because the objective is engineering quality, but feedback should remain specific, factual and actionable.
